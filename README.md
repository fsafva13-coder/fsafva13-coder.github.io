# safva.dev (portfolio)

Empty-but-live milestone for Week 4 of the FlyRank General AI Fluency track. Static HTML/CSS, no build step, deployed via GitHub Pages.

## Stack
- Plain HTML + CSS (single page, no framework, no build)
- Fonts: Space Grotesk (headings) + Inter (body), via Google Fonts
- Palette: `#FAF9F6` background / `#15181D` text / `#35415C` accent

## Structure
```
index.html
assets/
  favicon.svg      — logo mark, also used as favicon
  logo.svg         — mark + wordmark, for later use in the site header
  home-background.png — connective background texture (kept candidate from Kill Your Darlings)
```

## Deploy (GitHub Pages)
1. Create a new repo on GitHub (e.g. `safva-portfolio`), push this folder to it.
2. Repo → Settings → Pages → Source: deploy from branch `main`, folder `/ (root)`.
3. GitHub gives you a URL like `https://<username>.github.io/safva-portfolio/` — usually live within a minute or two.
4. Open that URL on your phone to confirm it's actually reachable, not just working locally.
